# 工作空间

工作空间是独立的协作模块，用于把**选中的**资产、工作台生成结果或**画布节点**分享给小团队，并维护简单进度板。也支持成员直接**上传本地图片/视频/文档（md/txt/csv）**到素材墙。

## 与「同步云端」的区别

| | 我的资产 / 云历史 | 工作空间 |
| --- | --- | --- |
| 归属 | 仅当前账号 | 空间成员可读 |
| 同步方式 | 登录后个人清单/历史上云 | **显式分享 / 本地上传**，不自动全量 |
| 数据表/API | `/api/assets` `/api/jobs` 等 | `/api/workspaces*` |
| 未登录 | 本机功能可用 | 仅引导登录，不挡其它模块 |

## 素材墙 vs 生成分享

| | 素材墙 | 生成分享 |
| --- | --- | --- |
| 用途 | 可复用的团队素材（定妆、场景、道具等） | 工作台/画布某次生成结果的过程快照 |
| 常见来源 | 「我的资产」分享、**本页本地上传**、画布文本节点 | 图/视频工作台历史、**画布图片/视频节点** |
| kind | `asset_image` / `asset_video` / `asset_text` / `asset_document` | `gen_image` / `gen_video` |
| 典型字段 | 标题、分类、备注 | 常带 **prompt / model**，便于对照生成 |
| source_type | `asset` / `local_upload` / `canvas`（文本） | `workbench_*` / `canvas` |

两块都是 `workspace_items`，只是按 kind 分 Tab 展示；权限与文件鉴权相同。

## 怎么用

1. 顶栏进入 **工作空间**，登录后创建空间，或粘贴同事的**空间邀请码**加入（不是注册账号用的站点邀请码）。
   - 本机会记住**最近打开的空间**：之后从顶栏再进工作空间会直接打开该空间，不必每次重选。
   - 需要换空间时，在详情页点 **切换工作空间**（`/workspace?list=1`）回到列表。
   - 分享弹窗会记住最近空间，并并发上传多选内容；再次进入空间会优先用本机会话缓存加速首屏（手动刷新仍拉最新）。
2. 分享入口：
   - 空间详情 **素材墙** →「去我的资产选择分享」
   - 空间详情 **生成分享** →「去图片/视频工作台分享」
   - **我的资产** 单卡/批量「分享到工作空间」→ 进素材墙
   - 图/视频工作台 **本机成功历史 / 云端历史** → 进生成分享
   - **画布**：节点悬停工具条「发布空间」、多选栏/右键「发布到空间」、顶栏菜单「发布选中到空间」、侧栏多选「发布空间」——仅上传有内容的图片/视频/文本节点副本（`source_type=canvas`），不自动同步整画布
   - 空间详情 **上传本地文件**（jpg/png/webp/mp4/webm，以及剧本/分镜文档 md/txt/csv）→ 进素材墙
3. 空间详情：
   - **素材墙 / 生成分享**：卡片展示上传者与时间；**点击卡片**打开详情（大图/视频/文档预览、上传者、prompt 等）；**卡面不展示提示词**（仅详情可见）；模型名只显示裸模型名（去掉 `channelId::` 前缀）
   - **文档素材**：`asset_document` 存完整文件（约 2MB 上限，UTF-8 文本），卡面仅摘要；详情按 mime 只读预览 Markdown / 纯文本 / CSV 表格，可下载；「存到我的资产」落为文本资产
   - **分类墙**：素材墙/生成分享顶部复用资产 taxonomy chips（人物 / 场景 / 道具 / 风格参考 / 分镜 / 其他 + 自定义 + 未分类）；**详情可手动改分类分区**；卡片上可**快速设分类**；**自动分类**：本地上传按文件名推断；从「我的资产 / 画布 / 工作台」分享时若无分类，会按标题/提示词/标签自动推断；墙内可点「智能归类未分类」对当前筛选再推断一次（仅自己可编辑的条目，所有者可改全部）
   - **文件夹（与分类正交）**：条目可选 `folder` 字段（如「定妆包 / 分镜-v2」），不替代分类。**建议使用顺序：先用批次文件夹归项目包 → 再用内容分类（人物/场景…）细分 → 勾选卡片后批量整理（分类/移入文件夹/终稿）。** 墙顶文件夹 chips **只列具体文件夹 + 未归入**（不设「全部」chip；默认不选=显示全部，再点已选 chip 或「清除」取消筛选；尚无文件夹时仅弱提示）；本地上传旁「放入」可选目标或新建；批量「移入文件夹」在勾选后展开；详情可改。智能归类**只动分类、不猜文件夹**
   - **批量操作**：素材墙 / 生成分享卡片左上角可勾选；**未勾选时**工具条仅全选 + 智能归类提示；**勾选后**展开分组：批量设分类、移入文件夹、标/取消终稿、存到我的资产、删除选中、清空选择（权限与单卡一致：创建者/所有者可改/删）
   - **终稿好找**：Tab 显示终稿数量；筛选条有「仅终稿」开关；列表**终稿优先置顶**；卡片琥珀色描边 +「终稿」角标；勾选态深色描边
   - **版本 / 终稿 / 改名**：条目可改 `title`、`category`、`folder`、`version`、`replaces_item_id`、`is_final`；创建者或所有者可在详情或墙面批量改，不重新上传文件
   - **团队决议（用 / 弃 / 改）**：任意成员可在详情对素材/生成条目投一票并写短评（每人一票，可改可撤）；卡片角标汇总用/改/弃数量；所有者可清除他人决议。适合九宫格批片，不改画布坐标
   - **进度板**：三列色块看板（待办 / 进行中 / 已完成）+ 顶部进度条；**拖拽任务左侧手柄到其它列可改状态**（创建者/所有者，下拉仍可用）；新建任务可 **多选本空间成员** 为负责人；创建者/所有者可改状态与负责人；创建者、所有者或负责人可 **上传多个交付物**（图片/视频，单任务最多 12 个，追加不覆盖）；卡片内网格缩略预览，可单条预览/下载/删除，也可清空全部
   - **成员**：名单与角色；**所有者可移除成员**（不能踢所有者；已分享内容仍保留，任务负责人会摘掉被踢用户）
4. 成员可预览、下载，并 **存到我的资产**（复制一份到自己的本地库，不合并原空间条目）。
   - **反向使用**：图/视频工作台与画布的「我的资产」选择弹窗中有 **工作空间** Tab，可直接把空间内图/视/文本导入本机后再当参考图或节点使用（复制，不改空间原文件）。
5. 所有者可重置邀请码、删除任意分享、**移除成员**、解散空间；成员只能删除自己分享的内容。

## 权限摘要

- 未登录：不能读写空间
- 成员：上传自己的、读全部、删自己的、建/改自己的任务（含多负责人）；可改自己条目的分类/文件夹/版本/终稿（含墙面批量与智能归类）；**可对任意条目投 用/弃/改 决议**；可批量把选中条目存到自己的资产
- 任务负责人：可追加/单删/清空该任务交付物
- 所有者：上述 + 删他人条目、改他人条目元数据（含批量）、清除他人决议、**移除成员**、重置邀请码、解散

## 限制（MVP）

- JSON 文件库，适合 2～10 人小团队；刷新查看更新，无 WebSocket
- 分享/上传媒体、文档与任务交付物按**上传者**个人云容量计费
- 文档仅支持 `.md` / `.txt` / `.csv`（默认约 2MB），不做协同编辑 / PDF / 服务端渲染
- 每个进度任务最多 **12** 个交付物；再次上传为追加，不会覆盖已有成果
- 版本/终稿是条目元数据，不是 blob 级历史；同一替代链上终稿为 best-effort（不强制库唯一）
- 决议是每人一票 + 短评（≤200 字），不是完整评论串；并发写可能 last-write-wins
- 不支持画布实时协作、匿名公开只读、自动双向同步个人库；画布发布为显式单节点/多选副本，不是项目 CRDT
