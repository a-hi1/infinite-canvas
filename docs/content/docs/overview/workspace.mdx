# 工作空间

工作空间是独立的协作模块，用于把**选中的**资产或工作台生成结果分享给小团队，并维护简单进度板。也支持成员直接**上传本地图片/视频**到素材墙。

## 与「同步云端」的区别

| | 我的资产 / 云历史 | 工作空间 |
| --- | --- | --- |
| 归属 | 仅当前账号 | 空间成员可读 |
| 同步方式 | 登录后个人清单/历史上云 | **显式分享 / 本地上传**，不自动全量 |
| 数据表/API | `/api/assets` `/api/jobs` 等 | `/api/workspaces*` |
| 未登录 | 本机功能可用 | 仅引导登录，不挡其它模块 |

## 素材墙 vs 生成分享

| | 素材墙 | 生成分享 |
| --- | --- | --- |
| 用途 | 可复用的团队素材（定妆、场景、道具等） | 工作台某次生成结果的过程快照 |
| 常见来源 | 「我的资产」分享、**本页本地上传** | 图/视频工作台本机或云端历史分享 |
| kind | `asset_image` / `asset_video` / `asset_text` | `gen_image` / `gen_video` |
| 典型字段 | 标题、分类、备注 | 常带 **prompt / model**，便于对照生成 |

两块都是 `workspace_items`，只是按 kind 分 Tab 展示；权限与文件鉴权相同。

## 怎么用

1. 顶栏进入 **工作空间**，登录后创建空间，或粘贴同事的**空间邀请码**加入（不是注册账号用的站点邀请码）。
2. 分享入口：
   - 空间详情 **素材墙** →「去我的资产选择分享」
   - 空间详情 **生成分享** →「去图片/视频工作台分享」
   - **我的资产** 单卡/批量「分享到工作空间」→ 进素材墙
   - 图/视频工作台 **本机成功历史 / 云端历史** → 进生成分享
   - 空间详情 **上传本地文件**（jpg/png/webp/mp4/webm）→ 进素材墙
3. 空间详情：
   - **素材墙 / 生成分享**：卡片展示上传者与时间；**点击卡片**打开详情（大图/视频预览、上传者、prompt 等）；模型名只显示裸模型名（去掉 `channelId::` 前缀）
   - **进度板**：三列色块看板（待办 / 进行中 / 已完成）+ 顶部进度条；新建任务可 **多选本空间成员** 为负责人；创建者/所有者可改状态与负责人；创建者、所有者或负责人可 **上传多个交付物**（图片/视频，单任务最多 12 个，追加不覆盖）；卡片内网格缩略预览，可单条预览/下载/删除，也可清空全部
   - **成员**：名单与角色
4. 成员可预览、下载，并 **存到我的资产**（复制一份到自己的本地库，不合并原空间条目）。
5. 所有者可重置邀请码、删除任意分享、解散空间；成员只能删除自己分享的内容。

## 权限摘要

- 未登录：不能读写空间
- 成员：上传自己的、读全部、删自己的、建/改自己的任务（含多负责人）
- 任务负责人：可追加/单删/清空该任务交付物
- 所有者：上述 + 删他人条目、重置邀请码、解散

## 限制（MVP）

- JSON 文件库，适合 2～10 人小团队；刷新查看更新，无 WebSocket
- 分享/上传媒体与任务交付物按**上传者**个人云容量计费
- 每个进度任务最多 **12** 个交付物；再次上传为追加，不会覆盖已有成果
- 不支持画布实时协作、匿名公开只读、自动双向同步个人库
