# 快速开始

如果你只是想先把项目跑起来，优先部署或启动 `web/` 前端。

## Vercel 部署

在 Vercel 中导入仓库即可，根目录 `vercel.json` 会构建 `web/`。默认 AI 请求由浏览器前台直连用户自己的 OpenAI 兼容地址；如果需要隐藏共享上游 Key，请使用 Docker 部署里的 `/ai-proxy` 同源代理。

## 本地启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建镜像：

```bash
docker build -t infinite-canvas .
docker run --rm -p 3000:3000 infinite-canvas
```

## 首次使用建议

- 先打开右上角配置弹窗，填入自己的 `Base URL`、`API Key` 和模型名；自部署代理模式可点击“添加服务器代理”。
- 如果需要提示词仓库内容，打开 `/prompts` 会由浏览器前端直连拉取并缓存到 IndexedDB。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 画布项目和“我的素材”默认保存在浏览器本地；登录后可选云同步（本地优先）。跨设备也可自行配置 WebDAV。
- 默认情况下 AI API Key 保存在浏览器本地，并由前端直接请求 OpenAI 兼容接口；自部署 `/ai-proxy` 模式可把真实上游 Key 放在服务器 `.env.proxy`。
