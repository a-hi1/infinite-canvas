# P0.5c 验稳收口

本阶段**不新开计费、不做画布全量同步**。目标是把已上线的「本地默认 + 可选云历史」收成可重复验收、可运维的基线。

代码基线参考：`main` 上云端相关提交（含同源登录、不占宿主机 8080、视频 media 回退、可选容器 `HTTP_PROXY` 等）。

## 原则（验收时不得破坏）

| 原则 | 含义 |
| --- | --- |
| 本地默认轨 | 未登录可用；配置/画布/素材/本机历史在浏览器 |
| 云可降级 | 上云失败不改写本地成功 |
| 登录仍 BYOK | 默认不改变生成路径；平台额度以后须显式开关 |
| 环境隔离 | 本机 `data/api` 与服务器 `data/api` 互不影响 |
| 浏览器代理 ≠ 容器出网 | 系统/Clash 代理不会自动进 Docker |

## 快速健康检查

服务器 / Linux：

```bash
chmod +x scripts/check-cloud-stack.sh
./scripts/check-cloud-stack.sh
# BASE_URL=http://127.0.0.1:3001 ./scripts/check-cloud-stack.sh
```

本机 Windows（dev-host 默认站点常为 3011）：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\check-cloud-stack.ps1
# 或指定：
# powershell -ExecutionPolicy Bypass -File .\scripts\check-cloud-stack.ps1 -BaseUrl http://127.0.0.1:3011
```

## C. Grok / vidgen 预期（不要当回归 bug）

| 现象 | 含义 |
| --- | --- |
| 中转站生成成功，有 `vidgen.x.ai` URL | 生成链路 OK |
| `/ai-proxy/media` 或 `from-url` 502 | **运行环境出网**拉不到 CDN，不是登录坏了 |
| 代理失败后预览回退原始 URL | 预期行为；浏览器能否播取决于访客网络 |
| 已有本地 `storageKey`/blob 再上云 | 不依赖再次访问 vidgen |

可选探测：

```bash
sudo docker compose -f docker-compose.local.yml exec ai-proxy \
  wget -S -O /dev/null --timeout=20 https://vidgen.x.ai/ 2>&1 | head -20
```

## E. 自动化已覆盖 vs 仍须人工

| 类别 | 状态 | 说明 |
| --- | --- | --- |
| `check-cloud-stack.*` | 可重复自动 | compose 三服务、页面、`/api/health`、`/ai-proxy/health`、platform 默认关、env 代理卫生 |
| `smoke-dual-track.*` | 可重复自动 | 停 `api` 后页面仍 200，`/api` 失败/502，再启回 health |
| A 中 UI 双轨（登录上云、幂等点两次、跨用户、401 只清一次） | **仍须人工** | 依赖真实账号与浏览器 |
| B2 服务器分册 | **仍须人工** | 目标机 `git pull` + compose + 备份 + HTTPS |
| C vidgen 出网 | 半自动 | 脚本 WARN 即可；勿当登录 bug |
| 平台扣积分 / 支付 | **后置** | 网关代码可在、默认关；不作为 P0.5c 出门条件 |
