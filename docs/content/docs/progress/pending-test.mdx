# 待测试

- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- WebDAV 同步：移除 Next.js 转发代理和连接方式选择，改为浏览器前端直接连接 WebDAV 服务。
- 提示词库：移除 Next.js route 抓取和服务端内存缓存，改为浏览器前端直连 GitHub 原始文件并缓存到 IndexedDB。
- 提示词库：移除已 404 的 `EvoLinkAI/awesome-gpt-image-2-API-and-Prompts` 来源。
- 前端构建：移除 Next.js，改为 Vite + React Router，并将前端目录调整为 `pages` / `components` / `stores` / `lib` / `layouts` / `styles`，需验证首页、图片/视频工作台、素材、提示词库和画布路由跳转。
- 前端构建：修复 TypeScript 严格检查下的构建报错。
- Vercel 部署：新增 `web` 和 `docs` 两个子项目的 Vercel 配置，需分别验证静态前端和文档站部署。
- Docker 部署：运行镜像从 Node serve 改为 nginx 静态托管，需验证前端路由刷新回退。
- 环境变量：移除过期的后端 `.env.example` 示例文件。
- AI 接口安全代理：新增 `ai-proxy` Docker 服务和 Nginx `/ai-proxy/` 同源转发，真实上游 API Key 存放在服务器 `.env.proxy`，前端可通过“添加服务器代理”创建 Base URL 为 `/ai-proxy` 的渠道，并用代理访问令牌作为 API Key；代理未启用访问令牌时前端允许 API Key 留空。代理渠道默认包含 `agnes-video-v2.0`，Agnes Video 走 `/v1/videos` 创建任务、`/agnesapi?video_id=...` 轮询；Agnes 创建/轮询遇到 429 会做短退避重试。需验证图片生成、参考图编辑、模型列表、文本问答、音频生成、OpenAI/Seedance/Agnes 视频任务和 CORS/鉴权/限流行为。
- 远程图片落盘：画布/图片工作台在接口返回 `https://imgen.x.ai/...` 这类远程 URL 时，会先尝试浏览器直连下载；若被 CORS 拦截，则回退到同源 `/ai-proxy/media` 转发后再写入本地 IndexedDB。`ai-proxy` 媒体白名单已补充 `imgen.x.ai` 与 `cdn.x.ai`。若当前是前端直连中转站且不依赖 `ai-proxy`，远程图无法下载时会保留远程 URL 继续展示，并在再次生成时自动退回文生图，避免把不可读远程图强行当编辑参考图。需验证：首次生成、修改提示词后重新生成、显式图生图/蒙版编辑在远程图场景下的提示。
- 视频参考图：Grok 固定走 `/v1/videos/generations`，不再回退 OpenAI `/videos`（避免 codex2api 等中转 404 噪音）。单图 `image:{url}`，多图 `reference_images`；本地图优先 data URI，远程 imgen 透传 URL。失败时前端展示上游 400 原文。需验证：本地参考图、远程 imgen 参考图、无参考图文生视频。
- 我的素材导入：支持直接选择本机图片、视频文件，也继续支持素材压缩包；新增素材表单支持视频类型，视频卡片可预览。需验证本地 png/jpg/webp、mp4/webm/mov 导入、压缩包导入，以及导入后在素材库中预览/下载。
- 默认中转站渠道：新安装默认渠道改为 `默认中转站`，Base URL 预填 `https://www.codex2api.com`，API Key 留空，预置 `gpt-image-2` / `grok-imagine-video` / `gpt-5.5` / `gpt-4o-mini-tts`。若本地仍是未改动的官方 OpenAI 默认渠道，会软迁移到该中转站；用户已自定义的渠道不被覆盖。需验证：填入中转站 API Key 后可直接选模型生图/视频/文本/音频，以及用户自建渠道仍可正常新增与使用。
