## 部署与端口（三套，勿混）

### 共性

- 主栈：`docker compose -f docker-compose.local.yml` → `app` + `api` + `ai-proxy`
- 容器内 app 听 3000；Nginx 同源 `/api/`、`/ai-proxy/`、可选 `/lan-ai/`
- Nginx **必须** `$http_host` + `X-Forwarded-Host` 保留端口（否则登录 403）
- **禁止被上游覆盖**：compose / nginx / 端口 / 同源 `/api` `/ai-proxy`
- 浏览器代理 ≠ Docker 出网；容器拉 `vidgen.x.ai` 超时可在根 `.env` 设 `HTTP_PROXY`/`HTTPS_PROXY` 后重建 api/ai-proxy；**服务器勿默认照搬本机 789x**

### 渠道 / 模型兼容（高频踩坑）

- `compatProfile`：auto / openai / openai-slim / grok-image / relay-fragile
- **视频自定义脚本参数**：`params.seconds` 是 number（例如 `4`），用于 Seedance `/v1/video/generations` 的 `duration`；不要退回字符串 `"4"`
- **原生 API Key Seedance 中转（openai2api）**：`/v1/video/generations`；带任意参考媒体时请求同时发送 `content[]` 与完全镜像的 `metadata.content`，供 New API Doubao 适配器展开；媒体项带 role：图片 `image_url`（单图 `reference_image`；**仅双图** `first_frame`/`last_frame`；**3+ 图全部 `reference_image`**——上游禁止 `last_frame` 与 `reference_image` 混用）、视频 `video_url` + `reference_video`、音频 `audio_url` + `reference_audio`。**不要**同时混发顶层 `image`/`video`/`audio` 或无 role 的参考数组，否则中转可能只消费首图分支。纯文生 modelScripts 仍可用；带任意参考媒体自动走内置完整 payload，任一素材读取失败不发请求、不退回文生。画布配置节点 `@` 只点名部分素材时仍附带全部已连接图/视/音。模型名示例：`doubao-seedance-2-0-260128` / `doubao-seedance-2-0-fast-260128`。火山 Agent Plan 仍 `/contents/generations/tasks`
- **Seedance 中转时长边界**：火山 Agent Plan 可用 `duration=-1` 智能时长；OpenAI2API/New API 中转的通用 `seconds` 校验不接受 `-1`，因此中转 UI 只提供 4/5/6/8/10/12/15 秒，旧 `-1` 配置在内置请求与纯文生 modelScript 参数中归一为 5 秒。不要把 Agent Plan 的智能 sentinel 原样复制进中转 `seconds`。
- **Seedance 参考视频本地校验**：只查边长 300–6000、宽高比 0.4–2.5、时长 2–15s/总 15s、50MB；**不要**用输出档像素总量（640×640～2206×946）拦参考视频
- **GPT 生图 openai2api 兼容**：`compatProfile=auto` 会把 `openai2api.com` 识别为 `relay-fragile`；文生图去掉易被拒的 `output_format` 并允许瘦身重试；多参考 edits 旁路必须全量发送 `images[]`，禁止只保留首图，且多参考失败时不允许用纯文生结果冒充成功
- **Grok 图生图**：JSON `POST /images/edits`；有参考图**不再**自动跳 `*-edit`；多参考必须完整 multi-image payload，**禁止静默只发第一张**
- **视频主机级自动适配**：`web/src/lib/video-host-profile.ts` 按 Base URL 收口 Grok 创建路径 / 是否允许 `/videos` 兜底 / Seedance 中转路径 / 多图压图；扩展新中转优先改 profile，避免散改 `video.ts`
- **Grok 视频路径（按主机 profile）**：用户当前选择永远优先；禁止硬塞不存在的模型插队；多参考勿退化首图。**codex2api/xAI** → `/videos/generations`；**内网 New API / 公网 openai2api** → **仅** `/video/generations`，创建、轮询、完成态内容下载均走 singular 路径（openai2api **不再**试 `/videos/generations`，实测 Invalid URL 404），**禁止** Grok 打 `/videos`（platform 48）。openai2api/New API 多参考首包优先完整 `images[]`（其 TaskSubmitReq 明确保留该字段），不以可能被忽略的 `reference_images` 抢先；选 1080p 时先发 1080p，只有创建失败才降档。旧会话若缓存了 `/videos` 成功路径，New API 风格下会忽略。**公网 Grok 多图：** 本机发完整多图字段；出片依赖渠道类型 + 上游 multi-ref；失败可改 Seedance
- **Grok 完成态 URL**：官方形状 `video.url`；`status=done` 时 url 可能空串/晚写——优先读嵌套 `video.url`，完成无地址再等约 3 分钟并试 content 下载，禁止过早当失败。**相对路径**（如 `/v1/videos/{id}/content`）按渠道 Base 解析并鉴权下载，不得当「无 URL」失败
- Sora/Veo：多路径 create/poll；图生禁止无参考文生回退
- Seedance/Agnes 保留；平台视频仍无参考素材服务端路径
- 参考图本地上限 6（平台积分图生图仍最多 4）
- 能力卡：`web/src/lib/model-capability.ts` 只暴露真实可选值
- **Grok 全模态本地画像已接入：** `web/src/lib/grok-model-profile.ts` 精确覆盖中转暴露的 14 个模型，文本/`grok-web-search` 继续复用现有 Responses 通路；生图、图片编辑、视频、TTS、STT、泛语音按任务隔离。未知自定义模型仍走旧启发式，不改变 `ModelChannel.models: string[]`。
- **Grok/TTS/STT 回归状态：** 生图 `auto` 仍发 `aspect_ratio`/`resolution`；图片编辑无参考图前置拒绝；多参考不丢图。普通 OpenAI 兼容渠道继续使用 `/audio/speech` 与 `/audio/transcriptions`；`web/src/lib/audio-host-profile.ts` 对 codex2api/xAI 主机上的精确 `grok-voice-tts` / `grok-voice-stt` 改走原生 `/tts`、`/stt`，请求分别为 `{text, language, voice_id}` 与 multipart `file + model=grok-stt + language=auto`。画布音频可生成 Text 子节点。音色选择按实际 TTS transport 隔离：原生 Grok 只显示 Eve/Ara/Rex/Sal/Leo，MiniMax 与 OpenAI 兼容模型各自只显示所属音色；切换模型会同步归一化历史音色，避免 UI 与请求值不一致。14 模型画像、音频、Grok 图/视频、Seedance 等 10 个测试文件共 131 项通过；音色专项 4 个测试文件 35 项、`tsc --noEmit` 与生产构建通过。**非付费路由核验：** 不带凭证请求 `https://www.codex2api.com/v1/tts` 与 `/v1/stt` 均返回 Sub2API 结构化 `401 API_KEY_REQUIRED`，而非旧 `/v1/audio/*` 的路由级 404，确认部署端点存在但未执行上游生成。带凭证 TTS/STT 成功态仍待用户人工点验；`grok-web-search` 联网行为与 `grok-voice-latest` 实时协议仍需中转契约。

## 工作方式硬约束

- 先理解与建议，**等用户确认再改代码**；未确认不提交、不推送
- **服务器不用助手部署**；只给命令（公司机同样，除非明确授权且只动 `ic3011`）
- 不破坏已实现能力：Grok 多参考、Sora/Veo/Seedance/Agnes、工作台并发/停止、云双轨、画布并发、工作空间既有能力、本地优先
- 动 ai-proxy / 部署 / 端口 / 安全代理时特别谨慎，并同步相关 Markdown
- 未登录 BYOK 必须可用；云失败不阻断本地
- 图生图/多参考：禁止静默只发第一张；禁止擅自把 Grok 模型改回自动 `*-edit`
- 工作空间文件夹：与 `category` 正交，不替代分类墙；智能归类不猜 folder
- 验收优先：`scripts/check-cloud-stack.*`、`scripts/smoke-dual-track.*`；说明仍须人工 UI 的部分
- **本机**改完会影响 Docker 镜像的代码后：**自动** `docker compose -f docker-compose.local.yml up -d --build` 相关服务（app / api / ai-proxy），不要等用户再说「重启」；纯文档可跳过。美国机/公司机仍由用户自部署
- 不要擅自大范围重构
